# E-commerce-Spending-Analysis

Overview
This is an AI model that predics how much a customer will spend in a year,based on a customer database.

The project uses
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Seaborn
- metrics
- LinearRegression

Project files
- Ecommerce Customers "Database"
- E-commerce Spending Analysis.pdf "Slide"
- E-commerce Spending Analysis.ipynb "Code"
- E-commerce Spending Analysis.py "Code"
- Graphic images in "images" folder
